# DecentWealth

Privacy-first portfolio tracker for iPhone, iPad, and Apple Watch.

DecentWealth tracks stocks, ETFs, digital assets, precious metals, real estate, and more in a single app — with no account, no servers, and no in-app tracking. All data stays on the device, and optional iCloud sync is end-to-end encrypted.

- **No account required** — no email, password, or personal information to start
- **On-device storage** — financial data stays on the user's device, not on a provider's servers
- **No bank linking** — no Plaid and no API keys; crypto is tracked via read-only public wallet addresses
- **Broad coverage** — 100,000+ stocks and ETFs, 15,000+ digital asset tokens across 18 networks, precious metals, real estate, and more
- **Apple ecosystem** — native iPhone, iPad, and Apple Watch apps, plus home- and lock-screen widgets
- **Free to download** — optional Premium for unlimited assets and advanced analytics
